# AGENTS.md — MANUAL MESTRE DE OPERAÇÃO DO FUT-LANCE

## 1. IDENTIDADE E OBJETIVO DO PROJETO

Este projeto é o Fut-Lance, um portal de futebol.

Site:
https://fut-lance.vercel.app/

O objetivo é manter o Fut-Lance como um portal profissional, confiável, atualizado, rápido, responsivo e otimizado para mecanismos de busca, especialmente o Google.

O projeto deve priorizar:

1. Informação correta.
2. Informação atualizada.
3. Fontes confiáveis.
4. Transparência.
5. SEO.
6. Boa experiência no celular.
7. Boa experiência no computador.
8. Performance.
9. Organização do código.
10. Preservação das funcionalidades existentes.
11. Segurança.
12. Preparação para monetização.
13. Não inventar informações.
14. Não publicar conteúdo sem aprovação do usuário quando essa regra se aplicar.

---

# 2. REGRA MÁXIMA: NÃO INVENTAR

É PROIBIDO inventar ou preencher informações sem confirmação.

Nunca inventar:

- notícias;
- resultados;
- placares;
- tabelas;
- posições;
- pontos;
- jogadores;
- escalações;
- lesões;
- transferências;
- contratações;
- declarações;
- datas;
- horários;
- competições;
- estatísticas;
- links;
- fontes;
- imagens;
- URLs;
- transmissões;
- canais;
- partidas;
- informações sobre jogos.

Se uma informação não puder ser confirmada por fonte confiável, NÃO inventar.

Se houver dúvida, informar que a informação não foi confirmada.

A precisão é mais importante do que velocidade.

---

# 3. DATA E HORA — REGRA OBRIGATÓRIA

ANTES de pesquisar, criar, atualizar ou publicar qualquer notícia, partida, tabela ou informação relacionada a eventos atuais:

1. Verificar a data atual.
2. Verificar o horário atual.
3. Considerar o fuso horário correto.
4. Confirmar se a informação encontrada ainda é atual.
5. Conferir a data de publicação da fonte.
6. Conferir quando o acontecimento realmente ocorreu.
7. Não confundir data da notícia com data do evento.

NUNCA assumir a data atual.

NUNCA usar informação antiga como se fosse notícia nova.

Quando publicar uma notícia, registrar corretamente:

- data;
- hora;
- título;
- conteúdo;
- fonte;
- imagem;
- autor, quando aplicável;
- SEO.

# 4. NOTÍCIAS — FLUXO OBRIGATÓRIO

NENHUMA notícia deve ser publicada automaticamente sem seguir este processo.

## ETAPA 1 — VERIFICAR DATA E HORA

Antes de pesquisar:

- verificar data atual;
- verificar horário atual.

## ETAPA 2 — PESQUISAR

Pesquisar notícias recentes em fontes confiáveis.

Priorizar:

- GE / Globo Esporte;
- ESPN;
- SporTV;
- UOL Esporte;
- Globo;
- CNN Brasil;
- TNT Sports;
- Gazeta Esportiva;
- Lance!;
- Goal;
- sites oficiais dos clubes;
- CBF;
- CONMEBOL;
- FIFA;
- sites oficiais das competições.

Quando possível, consultar mais de uma fonte.

Para informações importantes, cruzar as informações.

## ETAPA 3 — VERIFICAR

Antes de escrever:

- confirmar se a notícia é verdadeira;
- confirmar data;
- confirmar horário;
- confirmar clubes;
- confirmar jogadores;
- confirmar competição;
- confirmar números;
- confirmar declarações;
- confirmar origem da informação.

## ETAPA 4 — EVITAR DUPLICAÇÃO

Antes de criar uma notícia:

- verificar se já existe notícia sobre o mesmo assunto;
- verificar notícias recentes do mesmo tema;
- evitar publicar o mesmo conteúdo novamente;
- se houver atualização importante, atualizar a notícia existente quando isso fizer mais sentido.

## ETAPA 5 — ESCREVER

Criar conteúdo original e informativo.

Não copiar integralmente textos de outros sites.

Usar fontes jornalísticas apenas como referência factual.

Não fabricar citações.

Não atribuir declarações que não foram confirmadas.

## ETAPA 6 — MOSTRAR AO USUÁRIO

ANTES de publicar uma notícia, mostrar ao usuário para aprovação.

Enviar:

- título;
- resumo;
- conteúdo;
- fonte(s);
- data/hora;
- imagem escolhida;
- origem da imagem;
- licença da imagem;
- SEO planejado.

Aguardar aprovação.

## ETAPA 7 — PUBLICAR

Somente depois da aprovação:

- publicar;
- configurar SEO;
- configurar imagem;
- verificar página;
- testar no celular;
- testar no computador;
- confirmar que não existem erros.

Antes de utilizar uma imagem:

1. descobrir a fonte original;
2. verificar a licença;
3. confirmar se o uso é permitido;
4. somente depois utilizar.

# 13. ARMAZENAMENTO DE IMAGENS

# 14. ALT TEXT

Toda imagem deve possuir alt descritivo.

Exemplo:

Não usar alt="imagem" ou alt="foto".

O alt deve descrever o conteúdo da imagem de maneira natural.

# 16. BRASILEIRÃO — TABELA

A tabela do Brasileirão deve ser tratada como dado estruturado e importante.

Nunca preencher manualmente sem confirmação.

Campos obrigatórios:

- posição;
- clube;
- jogos;
- pontos;
- vitórias;
- empates;
- derrotas;
- gols pró;
- gols contra;
- saldo de gols.

Antes de atualizar:

1. Verificar data atual.
2. Pesquisar tabela atualizada.
3. Preferir fonte oficial ou fonte confiável estruturada.
4. Conferir todos os clubes.
5. Conferir pontos.
6. Conferir jogos.
7. Conferir vitórias.
8. Conferir empates.
9. Conferir derrotas.
10. Conferir gols pró.
11. Conferir gols contra.
12. Conferir saldo.
13. Conferir posições.
14. Verificar se os números são coerentes.

Não alterar apenas uma parte da tabela se isso puder deixar os dados inconsistentes.

Depois da atualização:

- verificar página;
- verificar ordenação;
- verificar responsividade;
- verificar se todos os clubes estão presentes;
- verificar se a tabela não foi quebrada.

# 39. NOTÍCIAS ANTIGAS

Não assumir que toda notícia antiga deve ser apagada.

Primeiro classificar:

### A — Ainda relevante
Manter.

### B — Precisa de atualização
Atualizar, se houver informação nova confiável.

### C — Conteúdo temporalmente incorreto
Corrigir ou remover.

### D — Duplicada
Mesclar ou remover quando apropriado.

### E — Falsa/não confirmada
Remover ou corrigir imediatamente.
